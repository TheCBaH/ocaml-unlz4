# unlz4

A pure OCaml LZ4 decompressor. It decodes raw LZ4 blocks and the LZ4 frame format, and runs
unchanged natively, under js_of_ocaml, and under Melange.

- **Frames**: independent and linked blocks, stored blocks, all four block maximum sizes, block
  and content checksums (XXH32, in OCaml), content sizes, dictionaries (explicit or resolved by
  ID), concatenated and skippable frames. LZ4 HC output decodes like any other. The legacy frame
  format is recognized and rejected.
- **Incremental**: `Unlz4.Frame.decode` is a resumable state machine with caller-owned input and
  output buffers, so a host can feed it chunks as they arrive, with backpressure. Memory is bounded
  by the frame's block size (at most two block buffers plus 64 KiB of history), never by the
  stream length.
- **Checked**: malformed input yields a structured `Unlz4.Error.t` (kind, compressed and decoded
  offsets, frame and block index), never an exception or an out-of-range access. Limits bound the
  block size, input, output, frame count and skipped bytes.
- **Portable**: the `unlz4` package depends only on the standard library: no C stubs, Unix,
  Bigarray or external hash library. `unlz4-bytesrw` adds
  [Bytesrw](https://erratique.ch/software/bytesrw) reader and writer filters.

Compression is out of scope. See [docs/design.md](docs/design.md) for the design,
[docs/plan.md](docs/plan.md) and [docs/tracker.md](docs/tracker.md) for status.

## Usage

```ocaml
(* A whole buffer. *)
match Unlz4.Frame.decompress compressed with
| Ok plain -> print_string plain
| Error e -> prerr_endline (Unlz4.Error.to_string e)

(* Incrementally, e.g. as chunks arrive. *)
let d = Unlz4.Frame.create ()
let out = Bytes.create 65536

let rec feed src off len ~eof =
  match Unlz4.Frame.decode d ~src ~src_off:off ~src_len:len ~eof ~dst:out ~dst_off:0 ~dst_len:65536 () with
  | Error e -> failwith (Unlz4.Error.to_string e)
  | Ok { consumed; produced; status } -> (
      print_string (Bytes.sub_string out 0 produced);
      match status with
      | Stream_end -> ()
      | Need_input when not eof -> () (* wait for the next chunk *)
      | _ -> feed src (off + consumed) (len - consumed) ~eof)

(* Bytesrw. *)
let plain =
  Bytesrw.Bytes.Reader.of_string compressed
  |> Unlz4_bytesrw.decompress_reads ()
  |> Bytesrw.Bytes.Reader.to_string

(* Raw blocks carry no size: bound the output. *)
let block = Unlz4.Block.decompress ~max_output:65536 raw_block
```

`examples/unlz4_cat.ml` decompresses files to stdout through Bytesrw, and `examples/js/` shows an
asynchronous Node host driving the decoder compiled with js_of_ocaml.

## Development

Use the devcontainer (`.devcontainer/`); CI runs every leg inside the same image. It provides
OCaml (4.14.4 by default, `OCAML_VERSION` to change), Dune, js_of_ocaml, Melange, ocamlformat and
Node. `make deps` installs the opam dependencies (the devcontainer runs it on creation).

| Command | What it does |
| --- | --- |
| `make ci` | Formatting check, build, native tests, corpus digests |
| `make test` | Native test suites |
| `make test-js` | The same suites under js_of_ocaml and Node, plus the JS example check |
| `make test-melange` | The same suites under Melange and Node (`UNLZ4_MELANGE=true`) |
| `make bench`, `make bench-js` | Decoding throughput over the corpus |
| `make consumer-test` | Build a project against the installed packages |
| `make release-test` | Build and test a copy of the sources without `vendor/` |
| `make reference-test` | Build and run the upstream fuzzer/frametest (bounded) |
| `make corpus-generate` | Regenerate `test/corpus` with the pinned upstream |

The tests replay a checked-in corpus generated by `test/reference/unlz4_ref.c` with upstream LZ4
v1.10.0 (the `vendor/lz4` submodule, `git submodule update --init vendor/lz4`). Ordinary builds and
tests need neither the submodule nor a C compiler.
